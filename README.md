# 📊 HHS System Capacity & Care Load Analytics

## 📌 Project Overview

The **HHS System Capacity & Care Load Analytics** project is a data analysis and forecasting dashboard designed to analyze system capacity, CBP custody, HHS care load, transfers, discharges, intake pressure, backlog indicators, and future HHS care trends.

The project uses data processing, validation, analytical metrics, visualization, and forecasting to provide an interactive view of system capacity and care-load patterns.

---

## 🎯 Objectives

- Analyze daily HHS care load
- Compare CBP custody with HHS care
- Analyze transfers and discharges
- Calculate total system load
- Analyze net daily intake
- Identify backlog pressure
- Analyze care-load growth
- Perform rolling-average analysis
- Measure system volatility and pressure
- Perform data-quality validation
- Generate a 30-day HHS care forecast
- Provide business insights through an interactive dashboard

---
